# AltCodes

AltCodes is a project that I started in March of 2023 to help me learn how to type characters used in Spanish that are special to English using the numpad on my keyboard. It can also be used to practice using the Spanish keyboard layout but isn't the best for doing so. One thing that should be kept in mind is that AltCodes is ment to be used on computers and is not very compatible with other devices.

![AltCodes Logo](https://raw.githubusercontent.com/Crystallizer196/AltCodes/main/icon.png "AltCodes Logo")
